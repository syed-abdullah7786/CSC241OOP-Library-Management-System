# Publishing checklist (manual-required)
1. Sign in to GitHub and create a repository named `CSC241OOP-Library-Management-System`.
2. Upload `main.cpp`, `README.md`, `UML-Class-Diagram.puml`, and `Implementation-Plan.md`.
3. Invite/add all team members if appropriate and ensure each person contributes commits.
4. Copy the actual repository URL into Section 13 of the Word report.
5. Optionally create a shareable online compiler project, verify it compiles, and paste its real URL into the report.
6. Do not use invented URLs or submit placeholders.
